# 第三部分：完整词库系统（最高优先级）

这是本项目最重要的要求之一。

## 1. 词库规模

建立可以支持至少30,000个俄语词条的数据库架构。

词条规模分为：

- 核心高频词：3,000个。
- 中级实用词：5,000个。
- 高级扩展词：7,000个。
- 医学、牙科、留学及生活专业词：5,000个。
- 常见口语、固定搭配和短语：10,000条。

上述为目标内容规模，不代表允许使用虚假、重复或低质量数据凑数。

必须区分单词词条、短语词条、不同词义和词形变化，避免重复计数。

如果没有可靠来源，不允许自行批量编造俄语单词、重音或中文释义。

优先使用许可证允许的公开词典数据、可合法使用的语料和经过审校的教学内容。

如来源数据不具备可靠的中文释义或重音，必须标注待审校状态，不得假装已经完成。

## 2. 每个词条的数据结构

每个词条应尽可能包含：

- 唯一词条 ID
- 俄语原形
- 正确重音标注
- 中文释义
- 词性
- 名词性别
- 单复数
- 名词变格
- 动词变位
- 动词体
- 常用词义
- 常见搭配
- 实用口语例句
- 中文例句翻译
- 拉丁转写
- 发音入口
- CEFR 或内部难度等级
- 使用频率
- 生活场景分类
- 同义词
- 反义词
- 易混淆词
- 来源和许可证
- 数据审校状态

不同词性适用不同字段，不适用的字段允许为空。

## 3. 俄语重音

所有教学词汇和例句必须尽可能提供正确重音。

要求：
- 使用 Unicode 重音符号。
- 正确处理 ё。
- 区分词形变化后的重音移动。
- 支持搜索时忽略重音符号。
- 支持带重音与不带重音显示切换。
- 对存在多种规范重音的词汇保留变体信息。
- 不允许使用随意猜测的重音作为已验证数据。

## 4. 词库必须真正可用

实现：
- 全局搜索
- 俄语搜索
- 中文搜索
- 模糊搜索
- 忽略重音搜索
- 词形还原查询
- 分类浏览
- 高频词排序
- 收藏
- 学习记录
- 单词发音
- 例句发音
- 闪卡
- 批量导入
- 数据更新
- 重复词检测

搜索必须具有合理的性能，不能因为词库扩大而明显卡顿。

## 5. 词库完整性验证

编写自动化检查程序，统计：

- 实际词条总数
- 去重后词条数
- 各等级词条数
- 词条缺失字段比例
- 重音覆盖率
- 中文释义覆盖率
- 例句覆盖率
- 重复词条数量
- 无法解析的数据数量
- 来源及许可证覆盖情况

生成真实的词库质量报告。

**如果实际只有500个词，必须明确写500个，不能宣称已经完成30,000词。**

# 第四部分：90天完整俄语课程

设计完整的90天教学体系，每天约60分钟。

每节课程包括：

1. 前一天知识复习。
2. 10—20个高频实用词。
3. 详细语法讲解。
4. 5—10句真实生活口语。
5. 听力练习。
6. 情景对话。
7. 互动练习。
8. 错题分析。
9. 课后复习。

课程内容按难度递进，避免前后知识断层。

## 必须覆盖的语法

- 俄语字母和发音规则
- 元音弱化
- 辅音清浊变化
- 重音规律
- 名词阴阳中性
- 单数和复数
- 六个格的完整变化规律
- 形容词变化
- 代词变化
- 动词第一和第二变位
- 过去时、现在时、将来时
- 完成体和未完成体
- 命令式
- 运动动词
- 数词与名词搭配
- 比较级
- 常见从句
- 口语省略
- 正式表达与日常表达差异

所有语法课程必须解释：
- 为什么这样变化
- 什么情况下使用
- 变化规律
- 常见例外
- 易错点
- 实际生活例句

不得只生成语法表格。

# 第七部分：面对面语音翻译

实现真正的中俄双向语音交流。

界面采用高级深色设计。

提供两个明显的语音按钮：

- 中文发言
- 俄语发言

基本流程：

用户说中文 → 语音识别 → 翻译成俄语 → 朗读俄语。

对方说俄语 → 语音识别 → 翻译成中文 → 朗读中文。

必须支持：
- 麦克风权限
- 录音状态提示
- 识别失败提示
- 手动修正识别结果
- 双语对话记录
- 重播语音
- 语速调整
- 中断和重新录音

优先确保轮流说话模式稳定。

不要未经测试就宣称实现真正的无延迟同声传译。

# 第十二部分：必须执行的验收标准

正式宣布某个功能完成前，必须验证它确实可用。

### 词库验收

- 词条数量真实可统计。
- 搜索能找到实际存在的词汇。
- 词形查询可用。
- 重音数据有来源或审校状态。
- 中文释义真实存在。
- 不存在大量重复词凑数。
- 数据库支持后续批量扩展。

### 课程验收

- 每一天都有独立课程内容。
- 不允许重复少量课程冒充90天。
- 每节课都有练习和答案。
- 学习进度可以保存。
- 复习机制能够正常运行。

### 翻译验收

- 输入新的中文句子能够得到实际俄语译文。
- 输入新的俄语句子能够得到实际中文译文。
- 网络失败时有明确提示。
- 翻译历史可以保存。

### 语音验收

- 能够实际录音。
- 能够识别中文和俄语。
- 能够调用翻译服务。
- 能够朗读译文。
- 对话记录可以查看。

### 界面验收

- 所有导航按钮可用。
- 页面没有明显布局错误。
- 没有大面积无意义空白。
- 没有占位功能冒充正式功能。
- 在不同尺寸的 iPhone 上布局正常。
